# 记忆系统设计文档

## 概述

让 AI 能够跨会话记住用户偏好和历史交互，借鉴人脑记忆巩固机制。

## 设计决策

| 话题 | 决策 |
|------|------|
| 存储方案 | localStorage |
| 内容格式 | MEMORY.md（Markdown 文档） |
| 注入方式 | System Prompt |
| 更新机制 | 工具为主，总结异步 |
| 容量管理 | 分区存储（摘要 + 最近） |
| 遗忘机制 | 追加抵消 |

---

## 1. 存储方案

**选择**：localStorage

**理由**：
- 记忆数据量预估 < 1MB，容量足够（5MB 限制）
- 面试演示项目，简单优先
- 封装 `MemoryStore` 类，方便后续替换

---

## 2. 记忆内容

**格式**：MEMORY.md（Markdown 文档）

**记忆类型**：
- 用户偏好（音乐、灯光、香氛）
- 历史场景（用户创建的场景配置）
- 重要对话（AI 提取的关键信息）

**修改方式**：借鉴 Claude Code 的字符串匹配替换机制

```typescript
// 工具参数
{
  oldText: "音乐：爵士",
  newText: "音乐：古典"
}
```

---

## 3. 记忆注入

**方式**：System Prompt 注入

每次对话时，将 MEMORY.md 内容注入到 System Prompt 中。

---

## 4. 记忆更新

**方式**：工具为主，总结异步

```
对话中 AI 判断有价值 → SaveMemory 工具 → 写入「最近」区
                                            ↓
                                    检测超长 → 异步总结
```

---

## 5. 容量管理

**方式**：分区存储 + 异步总结

### 文件结构

```markdown
# 记忆

## 摘要（长期记忆）
用户喜欢爵士乐和暖色灯光...

## 最近（短期记忆）
- 2025-12-29: 用户说不喜欢太亮的灯
- 2025-12-29: 用户提到喜欢薰衣草香
```

### 工作流程

| 人类 | AI 记忆系统 |
|------|-------------|
| 白天经历事情 | 对话中写入「最近」区 |
| 睡觉时整理记忆 | 异步总结，合并到「摘要」区 |
| 醒来记忆已巩固 | 下次对话用整理好的记忆 |

### 触发条件

记忆文件 > 2000 字符时触发总结

---

## 6. 遗忘机制

**方式**：追加抵消

不主动删除，而是追加"遗忘记录"，总结时自动抵消。

```
用户: "我不喜欢紫色"  → 记录: 用户不喜欢紫色
用户: "忘掉刚才说的" → 记录: 用户说忘掉"不喜欢紫色"
                            ↓
                    总结时两条抵消 → nothing
```

**设计理念**：
- 更像人脑：不是"删除"记忆，而是"覆盖/更新"认知
- 只追加不删除，实现简单
- 有完整记录，可追溯
