# 高德地图 API 验证实验

## 目标

验证高德地图 API 的数据质量，评估对氛围编排的价值。

## 测试接口

| 接口 | 说明 | 免费额度 |
|------|------|----------|
| 逆地理编码 | 经纬度→地址/POI | 5000次/天 |
| 天气查询 | 实时天气 | 300次/天 |

## 准备工作

1. 注册高德开放平台：https://lbs.amap.com/
2. 创建应用，获取 Web服务 API Key
3. 将 Key 填入 `.env` 文件

## 运行

```bash
# 安装依赖
npm install

# 运行测试
node test.js
```

## 测试场景

1. 上海陆家嘴（城市地标）
2. 沪杭高速某点（高速公路）
3. 杭州西湖（景区）
4. 北京故宫（历史景点）
