## 智能体交互流程

```
用户输入
    │
    ▼
┌─────────────────┐
│  Master Agent   │
│                 │
│  1. 接收消息    │
│  2. 判断意图    │
└────────┬────────┘
         │
    ┌────┴────┐
    │         │
    ▼         ▼
 简单请求   复杂氛围
    │         │
    ▼         ▼
 直接处理   ┌─────────────────┐
    │       │   Vibe Agent    │
    │       │   (异步执行)    │
    │       │                 │
    │       │  1. 获取环境    │
    │       │  2. 分析需求    │
    │       │  3. 规划方案    │
    │       │  4. 调用工具    │
    │       └────────┬────────┘
    │                │
    ▼                ▼
┌─────────────────────────────┐
│      SSE 推送到前端         │
│  · 文字回复                 │
│  · 思维链日志               │
│  · 氛围状态更新             │
└─────────────────────────────┘
```
