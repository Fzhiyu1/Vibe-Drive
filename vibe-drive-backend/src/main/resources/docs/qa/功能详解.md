# 功能详解 QA

## Q: 音乐系统怎么工作？

### 基本功能

| 功能 | 说明 |
|------|------|
| 搜索音乐 | 根据关键词搜索，返回匹配歌曲列表 |
| 播放音乐 | 播放指定歌曲（通过歌曲 ID） |
| 批量搜索 | 一次搜索 5-15 个关键词，快速构建歌单 |
| 批量播放 | 将搜索结果批量添加到播放列表 |

### 音乐种子（Music Seed）

AI 不直接搜索歌名，而是先生成「音乐种子」——描述氛围的风格标签。

**示例**：
- 输入：「深夜 + 雨天 + 放松」
- 音乐种子：`["爵士钢琴", "雨声白噪音", "慢节奏R&B", "轻音乐"]`
- 然后用这些种子去搜索音乐

**为什么用种子？**
- 避免 AI 编造不存在的歌名
- 风格标签更容易匹配到合适的歌曲
- 支持多样化推荐

### 播放控制

- 音量调节（0-100）
- 播放/暂停
- 上一首/下一首
- 播放列表管理

## Q: 灯光系统怎么工作？

### 基本参数

| 参数 | 范围 | 说明 |
|------|------|------|
| 颜色 | HEX 色值 | 如 #FF6B35（暖橙色） |
| 亮度 | 0-100 | 百分比 |
| 模式 | 4种 | 静态/呼吸/渐变/脉冲 |

### 四种灯光模式

| 模式 | 效果 | 适用场景 |
|------|------|----------|
| STATIC | 固定颜色 | 日常、阅读 |
| BREATHING | 明暗渐变 | 放松、冥想 |
| GRADIENT | 颜色渐变 | 派对、活力 |
| PULSE | 快速闪烁 | 音乐律动 |

### 流光效果

高级灯光效果，支持：
- 主色 + 副色对比
- 流动速度（0-5）
- 锐度控制

### 多区域控制

可分别控制：
- 仪表板区域
- 车门区域
- 脚部区域

## Q: TTS 语音系统怎么工作？

### 叙事功能

AI 会生成情感化的「串词」，通过 TTS 语音播报，营造沉浸感。

**示例**：
- 「夜深了，窗外的雨声和这首歌很配，让音乐陪你安全到家。」
- 「阳光正好，前方有个观景台，要不要停下来休息一下？」

### 技术实现

- 使用 Edge TTS（微软语音合成）
- 支持多种音色
- 流式播放，低延迟

### 触发时机

- 氛围切换时
- 环境变化时
- 用户请求时

## Q: 环境感知系统怎么工作？

### 感知维度

| 维度 | 数据来源 | 示例值 |
|------|----------|--------|
| GPS 标签 | 高德地图 | 闹市区、高架桥、隧道、郊区 |
| 天气 | 天气 API | 晴、多云、雨、雪、雾 |
| 时段 | 系统时间 | 清晨、上午、中午、傍晚、深夜 |
| 车速 | 车载传感器 | 0-200 km/h |
| 乘客 | 用户设置 | 独自、情侣、家庭、朋友 |
| 心情 | 用户输入 | 开心、放松、疲惫、压力大 |

### 安全模式

根据车速自动切换交互级别：

| 级别 | 车速 | 行为 |
|------|------|------|
| L1 正常 | <60 km/h | 完整功能 |
| L2 专注 | 60-100 km/h | 减少干扰，简化交互 |
| L3 静默 | ≥100 km/h | 最小化交互，安全优先 |

## Q: 记忆系统怎么工作？

### 记忆类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 长期记忆 | 经过总结的核心偏好 | 用户喜欢爵士乐和暖色灯光 |
| 短期记忆 | 近期的交互记录 | 今天用户说不喜欢太亮的灯 |

### 记忆操作

| 操作 | 说明 |
|------|------|
| 保存 | 追加新记忆到「最近」区 |
| 更新 | 修改已有记忆内容 |
| 读取 | 获取当前所有记忆 |

### 自动总结

当记忆超过 2000 字符时，系统会异步触发总结：
- 合并「长期」+「短期」记忆
- 生成新的精简摘要
- 清空短期记忆区

### 遗忘机制

当用户说「忘掉我喜欢爵士乐」：
- 不直接删除原记忆
- 追加一条遗忘记录
- 总结时自动抵消
