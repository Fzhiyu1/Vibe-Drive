# 使用指南 QA

## Q: 怎么部署 Vibe Drive？

### 环境要求

| 依赖 | 版本 |
|------|------|
| Docker | 20.x+ |
| Docker Compose | 2.x+ |
| Node.js | 20.x（仅开发） |
| Java | 21（仅开发） |

### 部署架构

Vibe Drive 分为两类服务：

| 类型 | 服务 | 特点 |
|------|------|------|
| 稳定服务 | TTS、音乐 API、Whisper | 很少更新，独立部署 |
| 动态服务 | 后端、前端 | 频繁更新，打包部署 |

### 部署步骤

**第一步：部署稳定服务（首次）**

```bash
cd docker
docker-compose -f docker-compose.stable.yml up -d
```

**第二步：打包动态服务**

```bash
cd scripts
./pack-prod.bat   # Windows
./pack-prod.sh    # Linux/Mac
```

**第三步：部署动态服务**

```bash
cd docker
docker-compose -f docker-compose.prod.yml up -d
```

### 服务端口

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端 | 80 | Nginx 托管 |
| 后端 | 8080 | Spring Boot |
| TTS | 3002 | 语音合成 |
| 音乐 API | 8081 | 网易云接口 |
| Whisper | 9000 | 语音识别 |

## Q: 怎么配置 API Key？

### 必需配置

在 `application.yml` 中配置：

```yaml
# AI 模型配置
langchain4j:
  anthropic:
    api-key: your-claude-api-key

  # 备用模型（可选）
  deepseek:
    api-key: your-deepseek-api-key
```

### 可选配置

```yaml
# 高德地图（位置服务）
amap:
  api-key: your-amap-key

# 音乐服务
music:
  api-url: http://localhost:8081
```

### 环境变量方式

也可以通过环境变量配置：

```bash
export ANTHROPIC_API_KEY=your-key
export DEEPSEEK_API_KEY=your-key
```

## Q: 怎么使用 Vibe Drive？

### 访问地址

- 本地开发：`http://localhost:5173`
- 生产部署：`http://your-domain`

### 基本操作

**对话交互**：
- 直接输入文字和 AI 对话
- 支持语音输入（需要 Whisper 服务）

**氛围请求示例**：
- 「帮我放松一下」
- 「来点适合开车的音乐」
- 「把灯光调成暖色」
- 「我想要浪漫的氛围」

**环境设置**：
- 点击左侧环境面板设置当前环境
- 或让 AI 生成：「假设现在是深夜下雨」

## Q: 怎么本地开发？

### 启动后端

```bash
cd vibe-drive-backend
mvn spring-boot:run
```

### 启动前端

```bash
cd vibe-drive-frontend
npm install
npm run dev
```

### 启动外部服务

```bash
# TTS 服务
cd vibe-drive-tts
npm install && npm start

# 音乐 API
cd services/music-api
go run main.go
```
